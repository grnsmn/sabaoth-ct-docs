# Come aggiungere immagini

## Inserire un'immagine nel testo

1. Clicca nel punto del testo dove vuoi inserire l'immagine
2. Nella barra degli strumenti dell'editor, clicca sull'icona **immagine** (un quadratino con una montagna stilizzata)
3. Si aprirà il **Media Manager** di TinaCMS

## Caricare una nuova immagine

Nel Media Manager:

1. Clicca il pulsante **"Upload"** (o trascina il file nell'area indicata)
2. Seleziona l'immagine dal tuo computer (formati supportati: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`)
3. Una volta caricata, la vedrai nell'elenco dei file
4. Cliccala per selezionarla — verrà inserita automaticamente nel documento

## Immagini già caricate in precedenza

Se l'immagine è già stata caricata in passato, la trovi nell'elenco del Media Manager. Puoi scorrere o cercare per nome.

## Consigli pratici

- **Dimensioni**: Prima di caricare, ridimensiona le immagini a una larghezza massima di **1200px**. Immagini troppo grandi rallentano il caricamento della pagina.
- **Nomi file**: Usa nomi senza spazi e senza caratteri speciali (es. `guida-mixer-01.jpg` invece di `Guida Mixer 01!.jpg`)
- **Cartelle**: Se stai aggiungendo immagini per una sezione specifica (es. Production), cerca di caricarle nella cartella corrispondente (es. `img/Production/`)

:::info
Le immagini caricate tramite l'editor vengono salvate nella cartella `static/img/` del sito.
:::
