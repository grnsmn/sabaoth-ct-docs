# Come accedere all'editor

## 1. Apri il pannello di amministrazione

Vai sul tuo browser e digita l'indirizzo:

```
https://sabaothctdocs.netlify.app/admin
```

Apparirà la schermata di login di TinaCMS.

## 2. Fai login con GitHub

Clicca sul pulsante **"Login with GitHub"** (o simile).

Il browser ti reindirizzerà a GitHub per confermare l'accesso. Se hai già fatto login su GitHub in precedenza, il processo è automatico. Altrimenti ti verrà chiesto username e password di GitHub.

:::tip Primo accesso
La prima volta potrebbe apparire una schermata che chiede di autorizzare TinaCMS ad accedere al repository. Clicca **"Authorize"** per procedere.
:::

## 3. Sei dentro!

Una volta fatto il login vedrai il pannello principale con due sezioni:

- **Documentazione** — tutti i file `.md` del sito (la maggior parte dei contenuti)
- **Documentazione (con componenti)** — i file `.mdx` che contengono elementi speciali come video

Clicca su una delle due sezioni per vedere l'elenco dei documenti.

## Problemi di accesso

Se vedi un messaggio di errore o non riesci ad accedere:
- Verifica di avere un account GitHub attivo
- Contatta chi gestisce il sito per verificare che il tuo account sia stato aggiunto come utente autorizzato su TinaCloud
