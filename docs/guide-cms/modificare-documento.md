# Come modificare un documento esistente

## 1. Trova il documento

Dal pannello principale, clicca su **"Documentazione"** per vedere l'elenco di tutti i file.

I documenti sono organizzati nelle stesse cartelle che vedi nella sidebar del sito (Team Media, Production, Fotografia, ecc.). Puoi navigare nelle sottocartelle cliccando sulle frecce.

Una volta trovato il documento che vuoi modificare, **cliccaci sopra**.

## 2. L'editor si apre

Si aprirà l'editor con due aree:

- **Sinistra** — il modulo con i campi da compilare (Titolo, Posizione nella sidebar, Contenuto)
- **Destra** — l'anteprima live di come apparirà la pagina (in alcuni casi)

## 3. Modifica il contenuto

### Titolo
Il campo **"Titolo"** è il nome della pagina che appare nella sidebar del sito.

### Contenuto
Il campo **"Contenuto"** è l'area principale dove scrivi il testo. Ha una barra degli strumenti in cima con i pulsanti di formattazione:

| Pulsante | Cosa fa |
|----------|---------|
| **B** | Testo in **grassetto** |
| *I* | Testo in *corsivo* |
| H1, H2, H3 | Titoli di diverso livello |
| Lista puntata | Elenco con •  |
| Lista numerata | Elenco con numeri |
| Immagine | Inserisci un'immagine |
| Link | Inserisci un collegamento |
| Codice | Blocco di codice tecnico |

### Posizione nella sidebar
Il numero nel campo **"Posizione nella sidebar"** determina l'ordine in cui il documento appare nella navigazione. Un numero più basso = appare prima.

## 4. Salva le modifiche

Quando hai finito di modificare, clicca il pulsante **"Save"** (o "Salva") in alto a destra.

Le modifiche vengono inviate automaticamente a GitHub. Il sito si aggiornerà entro **1-3 minuti**.

:::caution Attenzione
Non chiudere la finestra del browser mentre le modifiche vengono salvate. Aspetta che appaia la conferma di salvataggio.
:::
